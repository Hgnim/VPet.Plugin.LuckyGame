# VPet.Plugin.LuckyGame

## 项目简介

**LuckyGame**（幸运游戏）是一款[虚拟桌宠模拟器(VPet)](https://github.com/LorisYounger/VPet)的娱乐插件，包含比较经典的运气小游戏。

### ✨ 主要功能

- 💰 **代币兑换（Token Exchange）** - 使用桌宠钱兑换各种代币
- 🎡 **幸运转盘（Lucky Wheel）** - 转动转盘，试试你的运气
- 🎟️ **彩票系统（Lottery）** - 购买彩票，定期开奖，赢取丰厚奖励
- 🎰 **老虎机（Slot Machine）** - *开发计划，敬请期待*
- 🃏 **二十一点（Blackjack）** - *开发计划，敬请期待*

### 🌐 多语言支持(Multilingual support)

- 简体中文（zh-CN）
- 繁体中文（zh-Hant）
- English

### ⚠️ 重要声明

本插件仅供**本地娱乐**与**学习参考**使用
