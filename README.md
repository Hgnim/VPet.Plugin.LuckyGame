## 项目简介

**VPet.Plugin.LuckyGame**（幸运游戏）是一款专为[虚拟桌宠模拟器（VPet）](https://github.com/LorisYounger/VPet)设计的娱乐插件，为桌宠爱好者提供丰富的休闲小游戏体验。

### ✨ 主要功能

- 💰 **代币兑换（Token Exchange）** - 使用游戏内金币兑换各种代币
- 🎡 **幸运转盘（Lucky Wheel）** - 转动转盘，试试你的运气
- 🎟️ **彩票系统（Lottery）** - 购买彩票，定期开奖，赢取丰厚奖励
- 🎰 **老虎机（Slot Machine）** -（TODO）
- 🃏 **二十一点（Blackjack）** - （TODO）

### 🌐 多语言支持

- 简体中文（zh-CN）
- 繁体中文（zh-Hant）
- English

### ⚠️ 重要声明

本插件仅供**本地娱乐**与**学习参考**使用：

- 所有虚拟货币及游戏数据均存储于本地设备
- **不包含**任何真实货币交易、在线赌博或玩家间交易功能
- **不支持**任何形式的兑现或提现

详细信息请参阅[使用条款](./doc/使用条款.md)。
